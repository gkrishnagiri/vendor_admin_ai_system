 4.2. GENERAL RULES BEFORE ANY ACTION                                                                                                                                                                                                         +
 Access the application and login using the details provided in the above sections                                                                                                                                                            +
                                                                                                                                                                                                                                              +
 Before performing CREATE or DELETE:                                                                                                                                                                                                          +
 1. Always check existing records                                                                                                                                                                                                             +
 2. Avoid duplicates                                                                                                                                                                                                                          +
 3. If unsure, DO NOT proceed                                                                                                                                                                                                                 +
                                                                                                                                                                                                                                              +
 --------------------------------------------------                                                                                                                                                                                           +
 4.3. USERS PAGE                                                                                                                                                                                                                              +
                                                                                                                                                                                                                                              +
 VIEW USERS                                                                                                                                                                                                                                   +
 Step 1: Wait for list to load                                                                                                                                                                                                                +
 Step 2: Review existing users                                                                                                                                                                                                                +
                                                                                                                                                                                                                                              +
 CREATE USER                                                                                                                                                                                                                                  +
 Step 1: Check if user already exists in the users’ list table                                                                                                                                                                                +
 Step 2: If exists → DO NOT create duplicate                                                                                                                                                                                                  +
 Step 3: Enter Username                                                                                                                                                                                                                       +
 Step 4: Enter Email                                                                                                                                                                                                                          +
 Step 5: Enter Password                                                                                                                                                                                                                       +
 Step 6: Click "Create" and wait till the action is completed                                                                                                                                                                                 +
 Step 7: Check if the user created is now appearing in the users’ list table                                                                                                                                                                  +
                                                                                                                                                                                                                                              +
 DELETE USER                                                                                                                                                                                                                                  +
 Step 1: Check if user exists in the users’ list table                                                                                                                                                                                        +
 Step 2: If exists then delete the user by clicking on the Delete button against that user                                                                                                                                                    +
 Step 3: Check if the deleted user has disappeared in the users’ list table                                                                                                                                                                   +
                                                                                                                                                                                                                                              +
 --------------------------------------------------                                                                                                                                                                                           +
 4.4. ROLES PAGE                                                                                                                                                                                                                              +
                                                                                                                                                                                                                                              +
 VIEW ROLES                                                                                                                                                                                                                                   +
 Step 1: Click "Roles"                                                                                                                                                                                                                        +
                                                                                                                                                                                                                                              +
 CREATE ROLE                                                                                                                                                                                                                                  +
 Step 1: Check if role exists                                                                                                                                                                                                                 +
 Step 2: If the role already exists, then report it back and do not proceed further                                                                                                                                                           +
 Step 3: If the role does not exist, then enter the role name                                                                                                                                                                                 +
 Step 3: Click Create                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 DELETE ROLE                                                                                                                                                                                                                                  +
 Step 1: Confirm role not assigned to any user before deleting                                                                                                                                                                                +
 Step 2: Click Delete                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 --------------------------------------------------                                                                                                                                                                                           +
 5. PERMISSIONS PAGE                                                                                                                                                                                                                          +
                                                                                                                                                                                                                                              +
 VIEW PERMISSIONS                                                                                                                                                                                                                             +
 Step 1: Click "Permissions"                                                                                                                                                                                                                  +
                                                                                                                                                                                                                                              +
 CREATE PERMISSION                                                                                                                                                                                                                            +
 Step 1: Check if exists                                                                                                                                                                                                                      +
 Step 2: Enter name                                                                                                                                                                                                                           +
 Step 3: Click Create                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 DELETE PERMISSION                                                                                                                                                                                                                            +
 Step 1: Confirm safe to delete. The permission should not be assigned to any existing role before deletion.                                                                                                                                  +
 Step 2: Click Delete                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 --------------------------------------------------                                                                                                                                                                                           +
 6. ROLE → PERMISSION                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 ASSIGN                                                                                                                                                                                                                                       +
 Step 1: Click "Roles"                                                                                                                                                                                                                        +
 Step 2: Ensure the role already exists for which the permissions need to be provided                                                                                                                                                         +
 Step 3: Click on the Permission button for the role                                                                                                                                                                                          +
 Step 4: This will bring up the list of available permissions.                                                                                                                                                                                +
 Step 5: Ensure the Permissions already exist.                                                                                                                                                                                                +
 Step 6: Check if the Permissions are currently not enabled (or the checkbox not selected). If any of the permissions are already enabled, then report back that the permissions are already assigned (or enabled) and do not proceed further.+
 Step 7: If any of the permissions requested are not enabled (or the checkbox not selected) then tick the checkbox such that they are now enabled.                                                                                            +
 Step 8: To validate whether permission or permissions have indeed been enabled for the role, repeat the steps from 1 to 4. Verify whether the permissions have been enabled.                                                                 +
 This completes the mapping of the permission to the role.                                                                                                                                                                                    +
                                                                                                                                                                                                                                              +
 REMOVE                                                                                                                                                                                                                                       +
 Step 1: Uncheck box                                                                                                                                                                                                                          +
                                                                                                                                                                                                                                              +
 VALIDATION                                                                                                                                                                                                                                   +
 - Ensure role exists                                                                                                                                                                                                                         +
 - Ensure permission exists                                                                                                                                                                                                                   +
                                                                                                                                                                                                                                              +

                                                                                                                                                                                                                                              +

                                                                                                                                                                                                                                              +

 Option 2: Using psql (if installed)                                                                                                                                                                                                          +
                                                                                                                                                                                                                                              +

 8. SAMPLE SQL QUERIES                                                                                                                                                                                                                        +
                                                                                                                                                                                                                                              +
 View users:                                                                                                                                                                                                                                  +
                                                                                                                                                                                                                                              +
 SELECT * FROM users;                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 View roles:                                                                                                                                                                                                                                  +
                                                                                                                                                                                                                                              +
 SELECT * FROM roles;                                                                                                                                                                                                                         +
                                                                                                                                                                                                                                              +
 View permissions:                                                                                                                                                                                                                            +
                                                                                                                                                                                                                                              +
 SELECT * FROM permissions;                                                                                                                                                                                                                   +
                                                                                                                                                                                                                                              +
 Check role-permission mapping:                                                                                                                                                                                                               +
                                                                                                                                                                                                                                              +
 SELECT * FROM role_permissions;                                                                                                                                                                                                              +
                                                                                                                                                                                                                                              +
 Join example:                                                                                                                                                                                                                                +
                                                                                                                                                                                                                                              +
 SELECT u.username, r.role_name                                                                                                                                                                                                               +
 FROM users u                                                                                                                                                                                                                                 +
 JOIN roles r ON u.role_id = r.role_id;                                                                                                                                                                                                       +
